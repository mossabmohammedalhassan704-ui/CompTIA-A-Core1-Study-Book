# CompTIA A+ Core 1 (220-1201) Interactive Study Book

An original, single-file interactive English study book for CompTIA A+ Core 1. It is organized around the five exam domains and provides 27 expanded lessons, detailed notes, worked examples, guided practice, lesson checks with explanations, browser-local progress tracking, and a 54-question original review exam with answer rationales.

## Open the book

Open `index.html` locally, or visit the published GitHub Pages site once enabled.
